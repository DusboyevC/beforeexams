AS & A Level Mathematics 9709

1.5 Trigonometry

Graphs and exact values

  • sin and cos have period 360° (2π); tan has period 180° (π) and asymptotes at 90° ± 180°n.
  • Exact values:
θ 0 30° (π/6) 45° (π/4) 60° (π/3) 90° (π/2)
sin 0 ½ √2/2 √3/2 1
cos 1 √3/2 √2/2 ½ 0
tan 0 1/√3 1 √3 undefined
  • Transformed graphs: y = a sin(bx) + c has amplitude a, period 360°/b, and is shifted up by c.

Identities

  • tan θ ≡ sin θ / cos θ
  • sin²θ + cos²θ ≡ 1
  • Use these to prove identities: work on one side only, and convert everything to sin and cos.

Solving equations

  1. Get the equation in the form sin θ = k (or cos or tan).
  2. Find the principal value with the inverse function.

  3. Use the symmetry of the graph or the CAST diagram to find all solutions in the given interval: - sin θ = k: θ = α, 180° − α - cos θ = k: θ = ±α - tan θ = k: θ = α, α + 180°

  4. For sin 2x = k etc., solve over the doubled interval and then divide.

Example: solve 2 sin²x + 3 cos x = 0 for 0° ≤ x ≤ 360°. 2(1 − cos²x) + 3 cos x = 0 → 2 cos²x − 3 cos x − 2 = 0 → (2 cos x + 1)(cos x − 2) = 0. cos x = −½ (cos x = 2 is impossible), so x = 120°, 240°.

Inverse trig functions

  • sin⁻¹x has range −π/2 to π/2; cos⁻¹x has range 0 to π; tan⁻¹x has range −π/2 to π/2.

Exam tips and common mistakes

  • Don't divide both sides by sin x or cos x; you lose solutions. Factorise instead.
  • Check every solution lies inside the given interval, and give answers in degrees or radians as the question asks.
  • In proofs, show every step and finish with the expression on the other side.

Quick self-check

  1. Solve tan 2x = √3 for 0° ≤ x ≤ 180°. (30°, 120°)
  2. Prove (1 − cos²θ)/cos θ ≡ sin θ tan θ.
  3. Solve 3 sin x = 2 cos x for 0 ≤ x ≤ 2π. (0.588, 3.73)
