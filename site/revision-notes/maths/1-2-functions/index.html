AS & A Level Mathematics 9709

1.2 Functions

Key ideas

  • Function: a rule that maps each element of the domain to exactly one element of the range.
  • One-one function: each output comes from exactly one input. Only one-one functions have an inverse.
  • Composite function: fg(x) = f(g(x)), so apply g first. It exists only if the range of g lies within the domain of f.
  • Inverse function f⁻¹: undoes f. Its domain = the range of f, and its range = the domain of f.

Finding an inverse

  1. Write y = f(x).
  2. Rearrange to make x the subject.
  3. Swap x and y to get f⁻¹(x).
  4. State the domain of f⁻¹ (= the range of f).

Example: f(x) = 3 − 2/(x + 1) for x > 0. y = 3 − 2/(x + 1) → 2/(x + 1) = 3 − y → x + 1 = 2/(3 − y) → f⁻¹(x) = 2/(3 − x) − 1. For x > 0, the range of f is 1 < f(x) < 3, so the domain of f⁻¹ is 1 < x < 3.

Restricting the domain to make a function one-one

For a quadratic, restrict the domain to one side of the vertex. Complete the square to find it.

  • Example: f(x) = (x − 2)² + 1 is one-one for x ≥ 2 (or for x ≤ 2).

Graphs of f and f⁻¹

y = f⁻¹(x) is the reflection of y = f(x) in the line y = x.

Transformations

Transformation Effect on y = f(x)
y = f(x) + a Translation by (0, a)
y = f(x + a) Translation by (−a, 0)
y = af(x) Stretch parallel to the y-axis, scale factor a
y = f(ax) Stretch parallel to the x-axis, scale factor 1/a
y = −f(x) Reflection in the x-axis
y = f(−x) Reflection in the y-axis

When combining transformations, apply them in the right order. For y = 2f(x) + 3: stretch first, then translate.

Exam tips and common mistakes

  • Always state the domain of the inverse; examiners award a mark for it.
  • In fg(x), g is applied first.
  • When describing a transformation, give the type and the details: the translation vector, or the stretch direction and scale factor.
  • Check whether the vertex lies inside the given domain when finding a range.

Quick self-check

  1. f(x) = 2x + 1 and g(x) = x². Find fg(x) and gf(x). (2x² + 1; (2x + 1)²)
  2. Find f⁻¹(x) for f(x) = (x − 3)² + 2, x ≥ 3. (3 + √(x − 2), x ≥ 2)
  3. Describe the transformations that map y = x² onto y = 3(x − 1)².
