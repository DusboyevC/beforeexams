# 21 Alternating currents

## Key definitions
- **Alternating current**: a current whose direction reverses periodically, usually sinusoidally: x = x₀ sin ωt.
- **Root-mean-square (r.m.s.) value**: the value of the **steady direct current** that would produce the **same heating effect (power)** in a resistor as the alternating current.
- **Peak value (x₀)**: the maximum value.

## Equations
- **I_rms = I₀/√2**, **V_rms = V₀/√2** (for sinusoidal a.c.).
- **Mean power** in a resistor: P = I_rms V_rms = ½I₀V₀ (half the peak power).
- Peak power = I₀V₀.

## Rectification
- **Half-wave rectification**: a single diode, so only one half of each cycle passes through.
- **Full-wave rectification**: a **bridge rectifier** of four diodes, so both halves of the cycle pass in the **same direction** through the load.
- **Smoothing**: a **capacitor** connected in **parallel** with the load. It charges when the supply p.d. rises and discharges through the load when it falls, which reduces the ripple.
  - A larger capacitance or larger load resistance (larger RC) gives **less ripple**.

## Worked example
UK mains has V_rms = 230 V. Find the peak voltage.
V₀ = 230 × √2 = **325 V**

## Exam tips and common mistakes
- The r.m.s. definition must mention the **same power or heating effect** as a direct current.
- Mean power uses r.m.s. values; peak power uses peak values.
- On graphs, draw a rectified output as half-cycles above the axis; a smoothed output as a slowly falling line with small ripples.
