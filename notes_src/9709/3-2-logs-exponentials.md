# 3.2 Logarithmic and exponential functions

## Definitions and laws
- **y = aˣ ⇔ x = logₐ y**. ln x = logₑ x, and eˣ and ln x are inverse functions.
- **log(ab) = log a + log b**
- **log(a/b) = log a − log b**
- **log(aⁿ) = n log a**
- logₐ a = 1, logₐ 1 = 0.

## Graphs
- y = eˣ: passes through (0, 1), with the x-axis as an asymptote; it is always positive and increasing.
- y = ln x: passes through (1, 0), with the y-axis as an asymptote; it is defined only for x > 0.
- They are reflections of each other in y = x.

## Solving equations
- **Exponential equations**: take logs of both sides. For example, 3²ˣ⁺¹ = 7 → (2x + 1) ln 3 = ln 7 → 2x + 1 = 1.771 → x = 0.386.
- **Quadratic in eˣ**: e²ˣ − 5eˣ + 6 = 0 → let u = eˣ → (u − 2)(u − 3) = 0 → **x = ln 2, ln 3**.
- **Inequalities**: 2ˣ > 10 → x > ln 10 / ln 2. Be careful when dividing by a negative log (e.g. the log of a number less than 1).

## Reducing to linear form
- **y = axⁿ** → ln y = ln a + n ln x. Plot ln y against ln x: the gradient = n and the intercept = ln a.
- **y = abˣ** → ln y = ln a + x ln b. Plot ln y against x: the gradient = ln b and the intercept = ln a.
- Example: a graph of ln y against x passes through (1, 2.0) and (4, 3.5). The gradient = 0.5 = ln b, so b = e^0.5 = 1.65. The intercept = 1.5 = ln a, so a = e^1.5 = 4.48.

## Exam tips and common mistakes
- log(a + b) ≠ log a + log b.
- Reject solutions where you would need to take the log of a negative number or zero.
- In linear-form questions, find the gradient from the **given points**, not from estimated readings.
