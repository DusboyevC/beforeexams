# 2 Algebra and graphs

## Simplifying and expanding
- **Collect like terms**: 2a + 3b + 5a − 9b = 7a − 6b.
- **Expand**: 3x(2x − 4y) = 6x² − 12xy.
- **Two brackets**: (2x + 1)(x − 4) = 2x² − 8x + x − 4 = 2x² − 7x − 4.
- **Factorise fully**: 9x² + 15xy = 3x(3x + 5y).

## Factorising (Extended)
- **Grouping**: ax + bx + kay + kby = x(a + b) + ky(a + b) = (a + b)(x + ky).
- **Difference of two squares**: 4x² − 9y² = (2x − 3y)(2x + 3y).
- **Perfect square**: a² + 2ab + b² = (a + b)².
- **Quadratic**: 6x² + 7x + 2 = (2x + 1)(3x + 2).
- **Common factor first**: 2x³ + 6x² + 4x = 2x(x + 1)(x + 2).

**Completing the square**: x² + 6x + 2 = (x + 3)² − 9 + 2 = **(x + 3)² − 7**.

## Algebraic fractions (Extended)
- **Add**: x/3 + (x − 4)/2 = (2x + 3x − 12)/6 = **(5x − 12)/6**.
- **Multiply**: multiply tops and bottoms, then cancel.
- **Divide**: flip the second fraction and multiply.
- **Simplify**: (x² − 2x) / (x² − 5x + 6) = x(x − 2) / ((x − 2)(x − 3)) = **x / (x − 3)**.

## Indices in algebra
- (5x³)² = 25x⁶
- 12a⁵ ÷ 3a⁻² = 4a⁷
- 2ˣ = 32, so x = 5.

**Extended**: 32ˣ = 2 means 2⁵ˣ = 2¹, so x = 1/5. And 5ˣ⁺¹ = 25ˣ means x + 1 = 2x, so x = 1.

## Equations
**Linear**: 5 − 2x = 3(x + 7)
- 5 − 2x = 3x + 21
- −16 = 5x
- x = **−3.2**

**Simultaneous**: 2x + y = 7 and x − y = 2. Add them: 3x = 9, so x = 3, then y = 1.

**Rearranging**: make r the subject of A = πr²: r = √(A/π).

## Quadratic equations (Extended)
- **Factorising**: x² + x − 6 = 0 gives (x + 3)(x − 2) = 0, so x = −3 or x = 2.
- **Formula**: x = (−b ± √(b² − 4ac)) / 2a. For x² − 5x + 3 = 0: x = (5 ± √13)/2, so x = **4.30** or **0.697**.
- **Completing the square**: x² + 6x + 2 = 0 gives (x + 3)² = 7, so x = −3 ± √7.

**One linear, one non-linear**: y = x + 1 and x² + y² = 13.
- x² + (x + 1)² = 13
- 2x² + 2x − 12 = 0
- x² + x − 6 = 0
- x = 2, y = 3 or x = −3, y = −2

**Subject appears twice**: make x the subject of y = (2x + 3)/(x − 1).
- y(x − 1) = 2x + 3
- xy − y = 2x + 3
- xy − 2x = y + 3
- x = **(y + 3)/(y − 2)**

## Inequalities
- On a number line, use an **open circle** for < or > and a **closed circle** for ≤ or ≥.
- **Extended**: −3 ≤ 3x − 2 < 7 gives −1 ≤ 3x < 9, so −⅓ ≤ x < 3.
- If you multiply or divide by a negative, reverse the sign.
- **Extended, regions**: broken lines for strict inequalities, solid lines for inclusive ones. Shade the **unwanted** region unless told otherwise.

## Sequences
- **Linear**: 5, 8, 11, 14 goes up by 3, so nth term = **3n + 2**.
- **Simple quadratic**: 2, 5, 10, 17 is **n² + 1**.
- **Simple cubic**: 1, 8, 27 is **n³**.
- **Extended, quadratic**: if the second difference is constant, the sequence is quadratic. 3, 8, 15, 24 is **n² + 2n**.
- **Extended, exponential**: 3, 6, 12, 24 is **3 × 2ⁿ⁻¹**.

## Proportion (Extended)
- **Direct**: y ∝ x² means y = kx². If y = 18 when x = 3, then k = 2. When x = 5, y = **50**.
- **Inverse**: y ∝ 1/x means y = k/x.

## Graphs in practical situations
- **Gradient of a distance–time graph** = speed.
- **Conversion graphs**: read across and down.
- **Extended**: the **gradient of a speed–time graph** = acceleration. The **area** under it = distance. For a curve, draw a tangent to estimate the gradient at a point.

## Graphs of functions
- **Core types**: y = ax + b, y = ±x² + ax + b, y = a/x.
- Make a table of values, plot points and join with a smooth curve.
- Solve equations graphically by reading the x-values where two graphs meet.

**Curve shapes (Extended)**
- **Quadratic**: a U shape, or an upside-down U if a is negative.
- **Cubic**: an S shape.
- **Reciprocal**: y = a/x has asymptotes on the axes.
- **Exponential**: y = 2ˣ passes through (0, 1) and has the x-axis as an asymptote.
- **Turning point**: y = (x + 3)² − 7 has a minimum at (−3, −7).

## Differentiation (Extended)
- If y = axⁿ, then **dy/dx = naxⁿ⁻¹**.
- y = 4x³ − 5x + 2 gives dy/dx = 12x² − 5.
- **Gradient at a point**: put x into dy/dx.
- **Turning points**: solve dy/dx = 0.
- **Maximum or minimum**: the second differential is negative at a maximum and positive at a minimum.

**Worked example**: y = x³ − 3x².
- dy/dx = 3x² − 6x = 3x(x − 2) = 0, so x = 0 or x = 2.
- Points are (0, 0) and (2, −4).
- d²y/dx² = 6x − 6. At x = 0 it is −6, a **maximum**. At x = 2 it is 6, a **minimum**.

## Functions (Extended)
- f(x) = 3x − 5 means f(2) = 1.
- **Inverse**: y = 3x − 5 gives x = (y + 5)/3, so f⁻¹(x) = **(x + 5)/3**.
- **Composite**: with g(x) = x², gf(x) = g(f(x)) = (3x − 5)², and fg(x) = 3x² − 5.
- The **domain** is the set of inputs and the **range** is the set of outputs.

## Exam tips and common mistakes
- Watch signs when expanding a negative bracket.
- When dividing by a variable you can lose a solution, so factorise instead.
- gf(x) does f first.
